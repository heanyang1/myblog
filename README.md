# My Blog

A ~~very simple~~ blog that uses Jekyll with the most basic configuration and some QOL scripts.

## Third Party Plugins

- [jektex](https://github.com/yagarea/jektex) for rendering math.
- [jekyll-kroki](https://github.com/felixvanoost/jekyll-kroki) for rendering diagrams.

## Post series

Some long posts are split into multiple parts (e.g. there is a part introducing basic concepts in category theory inside DFA series) so I can reference parts of them separately. The links in the beginning of a part are generated by `_plugins/series.rb` and it reads the descriptions from `_data/series.yml`.

## Automatic numbering

The numbers of theorems, lemmas, equations, etc. are generated automatically by `_plugins/numbering.rb` [^documentation].

[^documentation]: So does this section in README. I found it useful so I kept it.

- Declare a theorem-like environment (any capitalized kind works) with a label:

  ```markdown
  **Lemma.**\label{lem:compose-monotone} Let ...
  **Proposition**\label{prop:right-adjoint-product} (title). ...
  ```

  The period inside the bold is optional and kept in the output, which becomes `**Lemma 3.**` / `**Proposition 4** (title).`

- Label an equation by putting the key in the `\tag` (a `:` marks the tag as a key, so fixed symbolic tags like `T-Num` are left alone):

  ```markdown
  \[ e = mc^2 \tag{eq:mass-energy} \]
  ```

  It renders as `\tag{7}` with the next equation number.

- Reference them anywhere in prose, code comments, or even inside math:

  ```markdown
  By \ref{lem:compose-monotone}, ...     -> By Lemma 3, ...
  the equation \eqref{eq:mass-energy}    -> the equation (7)
  ```

Keys are global across the blog, so references can point at other posts (the prose supplies the context, e.g. "... in Part 2"). Duplicated keys and unknown references are reported as build warnings.

## Run locally

1. [Install Jekyll](https://jekyllrb.com/docs/installation/)
2. On Arch Linux, you may need to add `~/.local/share/gem/ruby/[version]/bin` to `$PATH` to run `bundle`.
3. `bundle install && bundle exec jekyll serve`

In Emacs, `M-x host-blog` runs `jekyll serve` in a `*blog-server*` buffer and opens the site in your browser once ready.

## AI Usage

As mentioned in the about page, the posts are written by hand with a few exceptions. However, the code of the blog (custom plugins and scripts) are mostly written by LLM because
- [Jekyll's documentation](https://jekyllrb.com/docs/) is completely useless for implementing features I want.
- I don't want to learn Ruby just for configuring a static webpage generator.
- The code has nothing to do with the content of the blog.

## Troubleshooting

I don't know much about Jekyll, so I don't have any advice except:
- `rm .jekyll-cache` solves most of the problem
- If not, use an AI agent to solve it for you
