# Anyang's Blog

Personal blog built with Jekyll 4.4 (minima theme, Ruby/Bundler), deployed to GitHub Pages (`heanyang1.github.io`, baseurl `/myblog`) via GitHub Actions on push to `main`.

## Commands

- `bundle exec jekyll serve` — dev server (on Arch, `bundle` may need `~/.local/share/gem/ruby/[version]/bin` in `$PATH`)
- `bundle install` — install gems after Gemfile changes
- No test/lint setup; building the site (`jekyll build`) is the only check.
- `_config.yml` is NOT auto-reloaded — restart the server after editing it.
- If builds misbehave: `rm -rf .jekyll-cache` (fixes most issues).

## Architecture

- `_posts/` — content. Files named `YYYY-MM-DD-slug.md` with front matter (`layout: post`, `title`, optional `series`).
- `_plugins/` — custom Ruby plugins: `numbering.rb` (auto-numbering of theorems/equations, plus hyperlinks from every `\ref`/`\eqref` to its label), `series.rb` (series navigation links), `jektex-cache-fix.rb`, `jektex-trust.rb` (KaTeX trust mode so `\href` works inside math), `kroki-disk-cache.rb`.
- `_data/series.yml` — series metadata keyed by the `series` front matter value; a series post must have an entry here.
- `_layouts/post.html`, `_includes/` — templates. Theme is minima.
- `_site/` and `.jekyll-cache/` are generated — never edit.
- Math via jektex (MathJax), diagrams via jekyll-kroki.

## Conventions

- **Never hardcode theorem/equation numbers.** Use markers: `**Lemma.**\label{lem:foo}`, `\[ ... \tag{eq:bar} \]`, referenced as `\ref{lem:foo}` / `\eqref{eq:bar}`. Keys are global across the blog; duplicates/unknown refs produce build warnings. References render as links to the label (cross-post refs link to the other post's URL); see `numbering.rb` header for full syntax.
- Post `series` values must match a key in `_data/series.yml` (links are generated by `series.rb`).
- Post content is written by the author by hand; agents work on plugins/templates/scripts (Ruby/HTML), not on post prose.
- Deploy is automatic on push to `main` — don't force-push or create release tags.
